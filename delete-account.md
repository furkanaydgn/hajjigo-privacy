# Account and Data Deletion Request

Users can request deletion of their HajjiGo account and associated data at any time.

## How to Request Deletion

To request account and data deletion, please send an email with the subject  
"Account Deletion Request" to:

📧 moonborntech@gmail.com

Please include:
- The email address used to sign in to HajjiGo
- The authentication method used (Google Sign-In or Email/Password)

## What Will Be Deleted
Upon verification, we will permanently delete:
- User account
- Authentication data
- Associated personal data stored in our systems

## Retention
Some data may be retained if required by law or for security purposes, after which it will be deleted.

Deletion requests are processed within a reasonable timeframe.
